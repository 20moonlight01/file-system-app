# Файловый менеджер

Консольное C#-приложение для навигации, просмотра и выполнения операций с файловой системой.

## Основные возможности

* Навигация по дереву файловой системы с поддержкой относительных и абсолютных Unix-путей
* Просмотр содержимого каталога (форматированный вывод) и файлов в консоли
* Основные действия с файлами: перемещение, копирование, удаление, переименование
* Операции реализованы для локальной файловой системы, возможно расширение логики на иные системы
* Возможно гибкое расширение параметров консольных команд согласно принципам SOLID

---

## Поддерживаемые команды

### Управление подключением
* `connect [Address] [-m Mode]` — подключение к ФС по абсолютному пути (режим по умолчанию: `local`)
* `disconnect` — отключение от текущей ФС

### Навигация и просмотр
* `tree goto [Path]` — переход по указанному относительному или абсолютному пути
* `tree list {-d Depth}` — вывод дерева каталогов с ограничением по глубине (по умолчанию `-d 1`)
* `file show [Path] {-m Mode}` — просмотр содержимого файла в указанном режиме (по умолчанию `console`)

### Операции с файлами
* `file move [SourcePath] [DestinationPath]` — перемещение файла
* `file copy [SourcePath] [DestinationPath]` — копирование файла
* `file delete [Path]` — удаление файла или директории
* `file rename [Path] [Name]` — переименование файла
